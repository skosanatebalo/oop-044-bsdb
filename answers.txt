A pom.xml file is a file that has all the built dependencies that the Java application need to run. Without the pom.xml file
the Java program wont be  able to build or run the tests. It tells java the version of software it must run, what dependencies are needed,
and anything else needed to run the program.

In this context. The dependencies tes us that we will be using a sqlite to run the application.
The groupId tells the application that we will be using dependencies from xerial.org. This lets the java program know where to get its dependencies.
The artifactId tells java that we will be using jdbc, so the program will know to use jdbc from sqlite. The version tells us what version
of sqlite-jdbc we will be using.
